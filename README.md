# Spajanje PLTS tabela

Skript spaja "Otvoreni PLTS" i "Nepotvrđen prijem" tabele po koloni PLTS.

## Instalacija
pip install -r requirements.txt

## Pokretanje
1. Stavi oba Excel fajla u isti folder:
   - Otvoreni PLTS na dan 21.09.2026.xlsx
   - nepotvrđen prijem.xlsx
2. Pokreni:
   python spoji_tabele.py

Rezultat: `spojena_tabela.xlsx`
